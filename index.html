Firebase Crashlytics WeCom Alerts

An internal-use notification utility for Android smart-locker application diagnostics. This website provides information about the utility; it is not the alert processing service itself.

What this application does

The utility checks Crashlytics alert emails in an authorized Gmail account, optionally retrieves related event details using the Firebase Crashlytics API, and sends concise diagnostic notifications to a designated enterprise WeCom group.

Information included in alerts

When available, a notification may include the Android application version, cabinet identifier, exception type and description, code location, event timestamp and a link to the corresponding Firebase issue. If the Firebase API is unavailable, the utility may use alert email information instead, explicitly labeling the email time rather than treating it as the actual event time.

Who uses it

Access to the automation and receiving group is intended for authorized operational and engineering personnel. It is not a public consumer application and does not offer sign-in on this website.
